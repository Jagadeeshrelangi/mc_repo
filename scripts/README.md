# scripts

Repository-level automation and developer tooling.

## Contents

- Utility scripts for development, build, and release tasks.

## Adding a Script

- Keep scripts self-contained and documented with a short header.
- Never commit secrets; read credentials from environment variables only.

Most documentation tooling lives under `docs/tools/` (e.g.
`docs/tools/generate_bundle.py`) and is documented in `docs/README.md`.
