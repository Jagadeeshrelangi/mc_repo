# Mecha Connect — Frontend (Flutter)

Flutter application: on-demand mechanic booking, fuel delivery, parts
marketplace, and AI vehicle diagnosis, with real-time tracking.

## Contents

- `lib/` — Dart source (7 feature modules, single provider graph)
- `android/ ios/ linux/ macos/ windows/ web/` — platform shells
- `test/` — unit + integration suites (162 tests)
- `assets/` — app images
- `pubspec.yaml` — dependencies and asset manifest

## Commands

```bash
flutter pub get
flutter analyze
flutter test
```

See [docs/frontend/](../docs/frontend/) for architecture, design system, and
module documentation.
