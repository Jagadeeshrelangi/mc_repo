# Engineering Handbook

**Purpose:** The Mecha Connect engineering handbook and release history.

**Contents:**
- `ENGINEERING_HANDBOOK.md` — 20-chapter engineering handbook (canonical, PUBLIC)
- `CHANGELOG.md` — project release history

**Rule:** The handbook is built from PUBLIC documentation only. It never
references business plans, financials, internal notes, security docs, secrets,
private prompts, internal audits, or confidential material. Confidential
chapters (Business Model, competitor analysis, risk register) are maintained
outside the public documentation set and excluded from this folder.
